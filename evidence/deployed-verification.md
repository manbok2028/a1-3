# Vercel 공개 배포 검증 체크리스트

## 공개 주소

- Production: https://a1-3-eta.vercel.app
- AI 진단 화면: https://a1-3-eta.vercel.app/diagnosis.html
- 배포 브랜치: `main`

## 배포 전·후 확인 항목

| 확인 항목 | 확인 방법 | 통과 기준 |
| --- | --- | --- |
| 메인 화면 | Production URL 접속 | HTTP 200 및 메뉴 표시 |
| 페이지 이동 | 메인·AI 진단·제도 안내·세무사 연결·FAQ 메뉴 선택 | 각 페이지가 정상 표시 |
| 반응형 | 375px 모바일, 1440px 데스크톱에서 확인 | 메뉴와 입력폼이 화면을 넘지 않음 |

| 긴 입력 처리 | 상세 설명에 300자 초과 입력 | 길이 제한 안내 문구 표시 |
| API 실패 처리 | 키 미설정 또는 네트워크 오류 상황 | 재시도 안내 문구 표시 |

| AI 결과 | 정상 입력 후 실행 | 요약·제도 방향·체크리스트·태그·고지문 표시 |

## 실제 AI 배포 전환 절차

소스는 Gemini API를 사용하도록 구성되어 있습니다. API 키는 절대 GitHub에 커밋하지 않습니다.

1. Vercel 프로젝트 **Settings → Environment Variables**를 엽니다.
2. `GEMINI_API_KEY`에 본인의 실제 Gemini API 키를 등록합니다. 대상은 Production과 Preview를 선택합니다.
3. 선택 사항으로 `GEMINI_MODEL`을 등록합니다. 미등록 시 `gemini-3.5-flash`를 사용합니다.
4. `TAX_RESET_DEMO_MODE`가 있다면 삭제하거나 값을 `false`로 바꿉니다.
5. **Deployments → Redeploy**로 `main` 최신 커밋을 다시 배포합니다.
6. 아래 예시처럼 실제와 무관한 테스트 값으로 진단을 실행하고, 결과 화면을 캡처합니다.

```text
세목: 국세
체납액: 3,000,000원
체납 기간: 3개월~1년
현재 상황: 매출 또는 소득이 감소함
상세 설명: 일시 납부 가능 여부와 확인할 절차를 알고 싶습니다.
```

> 실제 체납 정보, 주민등록번호, 계좌번호, 연락처 등 민감한 개인정보는 테스트 입력에 넣지 않습니다. 결과는 정보 정리용 참고 자료이며, 실제 적용 가능 여부는 관할 기관과 세무 전문가에게 확인해야 합니다.
