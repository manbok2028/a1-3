# 동료 평가 설명서 · 체납리셋 (약 2분)

## 동료 평가자에게 말할 내용

안녕하세요. 저는 세금 체납자가 자신의 현재 상황을 쉽게 정리하고 다음에 확인할 행동을 준비하도록 돕는 **체납리셋**을 만들었습니다. 세무 지식이 부족한 개인 체납자와 자영업자가 대상입니다. 이 서비스는 세무·법률 자문이나 수임 알선이 아니라, 어려운 상황을 쉬운 말로 정리해 관할 기관 확인과 전문가 상담 준비를 돕는 **학습·평가용 공개 데모**입니다.

서비스는 메인, AI 상황 정리, 제도 안내, 세무사 연결 안내, FAQ·문의의 다섯 페이지로 구성했습니다. 상단 메뉴로 페이지를 이동할 수 있고, 모바일에서도 한 열로 자연스럽게 바뀌도록 반응형 화면을 적용했습니다. 다크 모드도 제공해 사용자가 보기 편한 화면을 선택할 수 있습니다.

핵심 기능은 AI 상황 정리입니다. 사용자가 세목, 체납액, 체납 기간, 현재 상황을 입력하면 JavaScript가 빈값과 금액을 먼저 검사합니다. 유효한 값만 `fetch('/api/diagnose')`로 보내고, Vercel의 Python Serverless Function이 입력을 다시 검증해 요약, 확인할 수 있는 제도 방향, 다음 행동, 매칭 태그를 JSON으로 돌려줍니다. 화면은 이 값을 결과 카드로 보여 줍니다. 응답이 늦으면 15초 뒤 안내하고, API 오류와 필수값 누락도 사용자 메시지로 처리했습니다.

배포본은 비용과 보안을 고려해 데모 모드로 운영합니다. 실제 OpenAI 키는 코드나 브라우저에 넣지 않고 Vercel 환경 변수에서만 관리하도록 설계했습니다. 데모 화면은 실제 상담 신청이나 개인정보 저장을 받지 않으며, 세무사 프로필도 실제 인물이 아닌 가상 예시 데이터입니다.

개발 과정에서는 Vercel이 Python 프로젝트로 자동 인식하면서 정적 HTML 페이지까지 API로 보내는 오류가 있었습니다. 배포 로그를 분석해 `vercel.json`에서 프레임워크를 Other로 명시했고, 이후 정적 페이지와 Python API가 각각 정상 동작하는 것을 확인했습니다. 공개 주소에서 진단 페이지 HTTP 200과 API 응답도 검증했습니다.

향후 실제 서비스로 확장하려면 세무사 자격 검증, 개인정보 동의·보관 정책, 실제 상담 요청 API, 법률 검토가 추가로 필요합니다. 따라서 현재 서비스는 정식 출시가 아닌, 안전한 정보 정리와 웹·AI 연동 흐름을 보여 주는 과제 결과물입니다. 감사합니다.

## 평가자가 직접 확인할 순서

1. [공개 서비스](https://a1-3-eta.vercel.app)에서 상단의 **AI 상황 정리** 메뉴를 연다.
2. 세목·금액·기간·현재 상황을 입력하고 결과 카드가 표시되는지 확인한다.
3. 하나 이상의 필수값을 비우고 오류 안내가 나타나는지 확인한다.
4. 모바일 너비에서 메뉴와 입력폼이 한 열로 표시되는지 확인한다.
5. 화면 상단의 **학습·평가용 공개 데모** 고지와 하단의 세무·법률 자문 고지 내용을 확인한다.
