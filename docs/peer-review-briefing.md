# 동료 평가자 설명서 — 체납리셋 (약 2분)

안녕하세요. 제가 만든 **체납리셋**은 세무 지식이 부족한 체납자가 자신의 상황을 차분히 정리하고, 관할 기관 또는 세무 전문가와의 상담을 준비하도록 돕는 AI 웹 서비스입니다. 개인 체납자와 자영업자를 주요 대상으로 정했습니다. 이 서비스는 세무·법률 자문이나 수임 알선이 아니라, 복잡한 상황을 이해하기 쉬운 말로 정리하는 학습용 정보 서비스입니다.

서비스는 메인, AI 상황 정리, 제도 안내, 세무사 연결 안내, FAQ·문의의 다섯 페이지로 구성했습니다. 상단 메뉴로 페이지를 이동할 수 있고, 데스크톱과 모바일에서 모두 읽기 쉽도록 반응형 CSS를 적용했습니다. 사용자는 다크 모드도 선택할 수 있습니다.

핵심 기능은 AI 상황 정리입니다. 사용자가 세목, 체납액, 체납 기간, 현재 상황을 입력하면 JavaScript가 먼저 빈값과 금액을 검사합니다. 유효한 입력만 `fetch('/api/diagnose')` 요청으로 전송합니다. Vercel의 Python Serverless Function은 다시 입력값을 검증하고, Gemini API에 안전한 안내문 생성을 요청합니다. 응답은 상황 요약, 확인해 볼 제도 방향, 다음 행동 체크리스트, 전문가 상담에 도움이 될 매칭 태그 형태로 화면에 표시됩니다.

오류도 사용자 경험의 일부로 설계했습니다. 필수 입력이 비어 있으면 즉시 안내하고, 네트워크 또는 API 오류가 나면 이해하기 쉬운 재시도 메시지를 보여 줍니다. 15초 안에 응답이 오지 않는 경우에도 기다리는 상태를 끝내고 안내합니다. 모든 AI 결과 하단에는 실제 적용 가능 여부를 관할 세무서·지자체·세무 전문가에게 확인해야 한다는 고지문을 고정했습니다.

세무사 연결 페이지의 프로필은 실제 인물이나 연락처가 아닌 가상 예시 데이터입니다. AI가 돌려준 태그로 어떤 전문 분야가 필요할지 살펴보는 흐름만 구현했으며, 개인정보를 저장하거나 수수료를 받는 기능은 넣지 않았습니다.

보안 측면에서는 API 키를 브라우저 코드나 GitHub에 넣지 않았습니다. `GEMINI_API_KEY`는 Vercel 환경 변수에서만 서버가 읽습니다. 실제 공개 배포에서 AI 기능을 켜려면 Vercel에 이 환경 변수를 등록하고 `TAX_RESET_DEMO_MODE`를 삭제하거나 `false`로 설정하면 됩니다. 이 설정 전에는 안전한 오프라인 미리보기 응답만 사용합니다.

마지막으로 프로젝트에는 서비스 기획서, AI 코딩 작업 기록, 배포·보안 안내, 미션 점검표, 자동 테스트와 증빙 체크리스트를 함께 정리했습니다. 그래서 화면 구현뿐 아니라 입력→요청→Python API→AI 응답→화면 표시라는 전체 웹 서비스 흐름을 설명할 수 있습니다.

## 평가자가 직접 확인할 순서

1. [공개 서비스](https://a1-3-eta.vercel.app)에서 상단 메뉴와 모바일 레이아웃을 확인합니다.
2. **AI 상황 정리** 페이지에서 정상 입력, 빈 입력, 긴 상세 설명을 각각 시도합니다.
3. AI 결과의 고지문과 오류·지연 안내를 확인합니다.
4. 세무사 연결 페이지에서 가상 프로필 및 전문 태그 필터 흐름을 확인합니다.
5. [미션 요구사항 점검표](mission-compliance.md)와 [배포 검증 체크리스트](../evidence/deployed-verification.md)를 확인합니다.
