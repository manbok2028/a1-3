# AI 코딩 도구 사용 과정 기록

이 문서는 AI 코딩 도구를 사용하되 결과를 검토·수정한 학습 과정을 재현하기 위한 텍스트 증빙이다.

| 단계 | AI에게 준 작업 단위 | 검토·수정한 사항 |
|---|---|---|
| 기획 | 체납자 대상 AI 정보 정리 서비스의 목적·타겟·페이지를 설계 | 자문·알선으로 오해될 표현을 제거하고 고지 문구를 모든 화면에 고정 |
| 화면 | 바닐라 HTML/CSS/JS로 5개 페이지와 반응형 메뉴 구현 | 모바일에서 메뉴가 겹치지 않도록 760px 이하 1열 레이아웃 추가 |
| AI API | Python Serverless Function의 입력 검증·OpenAI 호출 설계 | 주민번호 등 식별정보 입력 금지, 300자 제한, 15초 지연 처리 추가 |
| 결과 UX | JSON 응답을 요약·체크리스트·태그 카드로 표시 | `innerHTML` 출력 전 HTML 이스케이프 처리로 삽입 위험 완화 |
| 연결 UX | 태그로 세무사 프로필을 필터링 | 실명·연락처 대신 가상 프로필 JSON 사용, 신청 데이터는 저장하지 않음 |
| 검증 | 입력 검증·안전 태그 단위 테스트 | 누락 입력·알 수 없는 태그 제거·고지 문구 고정 테스트 추가 |

## 오류를 파악하고 수정한 예시

초기 구현에서 프론트는 AI 응답이 늦을 때 계속 기다릴 수 있었다. `AbortController`와 15초 타이머를 추가해 사용자가 “응답이 지연되고 있습니다”라는 안내를 받고 재시도할 수 있게 수정했다. 또한 백엔드가 반환한 태그를 그대로 신뢰하지 않고 허용 목록과 비교해 가상 프로필 필터가 예상 범위를 벗어나지 않게 했다.
